# 아침 경제 브리핑 (Morning Brief)

은행 취업을 위해 매일 아침 **경제 뉴스 · 증시 · 환율**을 모아서, 출근길 5분 안에 읽을 수 있게 정리해 주는 **아이폰 앱**입니다.
평일 아침 7시 30분(KST)에 브리핑이 만들어지면 알림이 옵니다. 내 컴퓨터는 꺼 둬도 됩니다.

기획 배경과 목표, 앞으로의 계획은 [기획서(PLAN.md)](PLAN.md)에 정리했습니다.

## 동작 방식

```
[시세 수집]  yfinance ─ 코스피·코스닥·S&P500·나스닥·다우·닛케이·상하이
                       원/달러·원/100엔·원/유로·원/위안·달러인덱스
                       미 국채 10년·WTI·금
[뉴스 수집]  RSS ───── 연합뉴스·한국경제·매일경제·구글뉴스(은행/금리)·CNBC·MarketWatch
      │
      ▼
[요약]  GPT(OpenAI) ─ 3줄 요약 / 증시 / 환율 / 금리 / 뉴스 5선(은행원 관점) /
                      금융권 이슈 / 오늘의 경제 용어 / 면접 대비 질문
      │
      ▼
[저장]  MongoDB Atlas ─ 날짜별 브리핑 · 지표별 시세 기록 · 기사
      │
      ▼
[앱]    아이폰 홈 화면 앱 ─ 오늘 / 지난 브리핑 / 아침 알림
```

- 시세 숫자와 뉴스 링크는 AI를 거치지 않고 코드가 직접 넣습니다. AI가 숫자나 주소를 잘못 만들어 낼 걱정이 없습니다.
- 매일 아침 실행은 홈서버가 맡습니다.

## 아이폰에서 쓰기 (처음 한 번)

1. **Safari**로 앱 주소를 엽니다. (주소는 가원에게 받습니다. 크롬 앱에서는 알림이 안 됩니다.)
2. 아래쪽 **공유 버튼**(네모에서 화살표가 나온 모양) → **홈 화면에 추가**를 누릅니다.
3. 홈 화면에 생긴 아이콘으로 앱을 열고 **설정 탭 → 알림 켜기 → 허용**을 누릅니다.
4. **시험 알림 보내기**를 눌러 알림이 오는지 확인합니다.

iOS 16.4 이상이 필요합니다.

## 폴더 구조

| 폴더 | 내용 |
|---|---|
| `apps/api` | 수집 · GPT 요약 · DB 저장 · API · 알림 (Python, FastAPI) |
| `apps/web` | 앱 화면 (React) |
| `infra/home-server` | 홈서버 설정과 배포 방법 (가원 관리) |
| `AGENTS.md` | Claude Code 같은 AI가 따르는 작업 규칙 |

## 바꾸고 싶을 때

Claude Code에게 하고 싶은 것을 그대로 말하면 됩니다. 어느 파일을 고칠지는 `AGENTS.md`에 적혀 있습니다.

- "KB금융 주가도 시세에 추가해 줘"
- "뉴스 출처에 OO신문 경제면을 추가해 줘"
- "요약에 '오늘의 은행주' 항목을 넣어 줘"
- "앱 색을 초록색 계열로 바꿔 줘"

바꾼 뒤에는 Claude Code가 `pnpm check`로 검사하고 브랜치에 커밋해 PR을 올립니다. 가원이 확인한 뒤 서버에 배포합니다.

## 내 컴퓨터에서 실행해 보기 (선택)

[uv](https://docs.astral.sh/uv/getting-started/installation/), Node 22, pnpm이 필요합니다. Python은 uv가 알아서 설치합니다.

```bash
pnpm install
cp .env.example .env        # 값 채우기 (항목 설명은 파일 안에)
pnpm dev:api                # 터미널 1: API
pnpm dev:web                # 터미널 2: 앱 화면 → http://localhost:5173
pnpm brief:run --no-push    # 브리핑 한 번 만들기
pnpm check                  # 검사
```

## 참고

- 시세는 Yahoo Finance 기준이며, 은행 고시 환율(매매기준율)과는 조금 다를 수 있습니다.
- GPT 요약은 하루 한 번이라 비용이 적습니다. 정확한 사용량은 OpenAI 대시보드에서 확인합니다.
- `.env`에 `NOTION_TOKEN`·`NOTION_DATABASE_ID`를 넣으면 앱과 함께 Notion 데이터베이스에도 브리핑을 올립니다.
